# Internationalization i18n
BCD-UI supports i18n in the form of a static i18n file and a database table.
BCD-UI comes with a default set of English messages.
In addition, a page-wide language is set to choose the right set.
Renderer and Widgets support i18n if the output label or text is prepended with UTF-8 char `\uE0FF`.  \
For example `caption="&#xE0FF;bcd_RootCauseAnalysis"`

Thus, usually no manual translation is necessary but can also be done with: 
- in JavaScript see element syncTranslateFormatMessage().
- in XSLT stylesheets use a xsl:param name="i18n", it is set automatically for all stylesheets

The file at WEB-INF/bcdui/messages.xml has the form
````xml
<Data>
  <R id="R0"><C>bcd_EmptyString</C><C></C><C>en</C></R>
  <R id="R1"><C>bcd_RootCauseAnalysis</C><C>Root Cause Analysis</C><C>en</C></R>
  <R id="R2"><C>bcd_GridPage</C><C>Grid page</C><C>en</C></R>
  ...
</Data>
````

The BindingSet bcd_i18n is used to access the i18n table.
````sql
CREATE TABLE BCD_I18N (
   I18N_KEY    VARCHAR(255),
   I18N_LANG   VARCHAR(255),
   I18N_VALUE  VARCHAR(255),
   PRIMARY KEY(I18N_KEY, I18N_LANG)
);
````
