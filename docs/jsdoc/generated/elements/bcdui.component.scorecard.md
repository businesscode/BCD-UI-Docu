# Package bcdui.component.scorecard

The implementation of the Scorecard class.


----
<h4>Classes</h4>



[Scorecard](bcdui.component.scorecard.Scorecard.md)\
Creates a convenience standard scorecard renderer.

[ScorecardModel](bcdui.component.scorecard.ScorecardModel.md)\
Creates a scorecard-model from a scorecard definition, the scorecard model is derived [DataProvider](bcdui.core.DataProvider.md)Format of scorecard definition is defined by XSD http://www.businesscode.de/schema/bcdui/scorecard-1.0.0This scorecard does all calculations and also transposes data if necessary.
