# buildRequestTransformator()
<span hidden class='htmlPackage'>bcdui.widget.inputField</span>


Transformator for building a MultiLevelSuggestion requestConnect the inputfield with a (auto)model using this as request builder (input doesn't matter, use guistatus)And refresh it via additionalFilterXPath, same as for plain suggest

````js
// Usage
bcdui.widget.inputField.buildRequestTransformator();
  ````

**Returns**: {void}
