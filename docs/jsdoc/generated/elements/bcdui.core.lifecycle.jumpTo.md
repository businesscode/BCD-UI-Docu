# jumpTo()
<span hidden class='htmlPackage'>bcdui.core.lifecycle</span>


Jumps to another url optionally setting status document, this function is executed asynchronously.

````js
// Usage
bcdui.core.lifecycle.jumpTo( href );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| href | string |  | target URL to jump to. |
| statusDocument? | DomDocument |  | status document to pass as guiStatusGZ parameter to href. |


**Returns**: {void}
