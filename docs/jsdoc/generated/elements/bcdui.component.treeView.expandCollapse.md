# expandCollapse()
<span hidden class='htmlPackage'>bcdui.component.treeView</span>


Expand or collapse a level for a treeView renderer

````js
// Usage
bcdui.component.treeView.expandCollapse( rendererId, levelId, isExpand );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| rendererId | string |  | Id of the treeView's renderer |
| levelId | string |  | Which level to change |
| isExpand | boolean |  | True for expand, false for collapse |


**Returns**: {void}
