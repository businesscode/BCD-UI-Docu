# reDisplay()
<span hidden class='htmlPackage'>bcdui.component.scorecardConfigurator</span>


Refreshes the scorecard drag'n drop areaThis is e.g. necessary when a template is applied or the layout is cleaned

````js
// Usage
bcdui.component.scorecardConfigurator.reDisplay( scorecardId );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| scorecardId | string |  | The id of the linked scorecard |


**Returns**: {void}
