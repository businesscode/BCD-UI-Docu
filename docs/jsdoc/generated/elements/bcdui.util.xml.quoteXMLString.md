# quoteXMLString()
<span hidden class='htmlPackage'>bcdui.util.xml</span>


Replaces the XML control characters in the specified string with the appropriatepre-defined entities.

````js
// Usage
var ret = bcdui.util.xml.quoteXMLString( xmlString );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| xmlString | string |  | The string to be processed. |


**Returns**: {string} - The parameter with XML control characters replaced.
