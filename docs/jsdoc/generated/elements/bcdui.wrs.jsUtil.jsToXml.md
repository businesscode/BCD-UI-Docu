# jsToXml()
<span hidden class='htmlPackage'>bcdui.wrs.jsUtil</span>

````js
// Usage
bcdui.wrs.jsUtil.jsToXml( arg );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| arg | Object |  | The JavaScript object following Wrs conventions, from which the XML document is to be created |
