# applyScale()
<span hidden class='htmlPackage'>bcdui.wrs.wrsUtil</span>


applies number rounding at defined wrs:Header/wrs:Columns/wrs:C/@scale

````js
// Usage
var ret = bcdui.wrs.wrsUtil.applyScale( wrsDoc );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| wrsDoc | DomDocument |  | the Wrs document to apply changes on |


**Returns**: {DomDocument} - wrsDoc
