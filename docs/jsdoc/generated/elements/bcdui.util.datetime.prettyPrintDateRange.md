# prettyPrintDateRange()
<span hidden class='htmlPackage'>bcdui.util.datetime</span>


Pretty prints a date range

````js
// Usage
var ret = bcdui.util.datetime.prettyPrintDateRange( startDate, endDate );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| startDate | (Date\|string) |  | First day of the date range |
| endDate | (Date\|string) |  | Last day of the date range |


**Returns**: {string} - A string describing the date range (e.g. "Jul 2010" or "CW 30, 2010").
