# Package bcdui.component.chart

The chart package contains classes to draw charts and for drawing primitives like circles, lines and polylines in SVG,see [bcdui.component.chart.SVGDrawer](bcdui.component.chart.SVGDrawer.md).You can define a chart with js calls with [bcdui.component.chart.Chart](bcdui.component.chart.Chart.md) as well as be providing a XML definition according to http://www.businesscode.de/schema/bcdui/charts-1.0.0 using [bcdui.component.chart.XmlChart](bcdui.component.chart.XmlChart.md).


----
<h4>Classes</h4>



[Chart](bcdui.component.chart.Chart.md)\

[ChartEchart](bcdui.component.chart.ChartEchart.md)\

[XmlChart](bcdui.component.chart.XmlChart.md)\
Implements XML-definition interface.
