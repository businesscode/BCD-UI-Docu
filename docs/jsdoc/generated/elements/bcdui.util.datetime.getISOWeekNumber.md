# getISOWeekNumber()
<span hidden class='htmlPackage'>bcdui.util.datetime</span>


Calculates the ISO week number the date belongs to. Derived from Klaus Tondering's Calendar document.

````js
// Usage
var ret = bcdui.util.datetime.getISOWeekNumber( date );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| date | (Date\|string) |  | date for which to determine the CW |


**Returns**: {integer} - cw
