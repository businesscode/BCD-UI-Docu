# excludeDimMember()
<span hidden class='htmlPackage'>bcdui.component.cube.configurator</span>


Excludes (server side filter) the occurrences of a selected dimension member, i.e. for example all values for a countryResults in f:Filter expressions

````js
// Usage
bcdui.component.cube.configurator.excludeDimMember();
  ````
**Parameters**: _None_

**Returns**: {void}
