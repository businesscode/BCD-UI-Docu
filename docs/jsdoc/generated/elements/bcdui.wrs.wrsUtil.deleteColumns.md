# deleteColumns()
<span hidden class='htmlPackage'>bcdui.wrs.wrsUtil</span>


Phsyically drops columns from Wrs

````js
// Usage
bcdui.wrs.wrsUtil.deleteColumns( wrs, colIdArray );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| wrs | DomElement |  | WRSRootNode: Pointing to wrs:Wrs |
| colIdArray | Array.\<string> |  | Array of column-ids to remove |


**Returns**: {void}
