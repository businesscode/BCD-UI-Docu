# Package bcdui.util.url

Utilities for working with URLs


----
<h4>Classes</h4>



----
<h4>Functions</h4>



[extractFolderFromURL()](bcdui.util.url.extractFolderFromURL.md)\
Gets the folder containing the document identified by the URL.

[isAbsoluteURL()](bcdui.util.url.isAbsoluteURL.md)\
Tests if the specified URL is an absolute URL or null.

[resolveToFullURLPathWithCurrentURL()](bcdui.util.url.resolveToFullURLPathWithCurrentURL.md)\
Converts a relative URL (like ../Ziplet) to a full URL path (like(/myApp/ZipLet), based on the current page location..

[resolveURLWithXMLBase()](bcdui.util.url.resolveURLWithXMLBase.md)\
Resolves a URL with its correct xml:base.

[translateRelativeURL()](bcdui.util.url.translateRelativeURL.md)\
This utility function applies a relative URL to a base URL and returns theresulting URL.
