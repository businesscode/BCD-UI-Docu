# isValidDate()
<span hidden class='htmlPackage'>bcdui.util.datetime</span>


Checks if date passed is valid date

````js
// Usage
var ret = bcdui.util.datetime.isValidDate( date );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| date | string |  | The date string to be parsed. |


**Returns**: {boolean} - Whether the parsed "date" argument is valid date string.
