# isAbsoluteURL()
<span hidden class='htmlPackage'>bcdui.util.url</span>


Tests if the specified URL is an absolute URL or null. In this case itreturns true and false otherwise.

````js
// Usage
var ret = bcdui.util.url.isAbsoluteURL( url );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| url | string |  | The URL to be inspected. |


**Returns**: {boolean} - True if the URL is either null or an absolute URL.
