# getWidgetCaption()
<span hidden class='htmlPackage'>bcdui.widget</span>


Get widgetCaption information from the given target

````js
// Usage
var ret = bcdui.widget.getWidgetCaption( elOrId );
  ````
**Parameters**:


| Name     | Type     | Default  | Description |
|----------|----------|----------|-------------|
| elOrId | (HtmlElement\|string) |  | An existing HTML element or its id representing a widget targetHtml |


**Returns**: {string} - string of found widgetCaption or empty string
